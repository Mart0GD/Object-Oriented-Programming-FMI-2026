## Множествено наследяване

В това упражнение ще се занимаваме с концепцията за **множествено наследяване** - нейните плюсове и минуси, как по точно е имплементирана в езика **C++** 

Нека започнем с това как изглеждаше един клас линейно в паметта:

~~~.cpp
struct A
{
    int  a;      // 4 bytes
    char symb;   // 1 byte
                 // 3 bytes padding
};

Разпределение в паметта:

+-------------------+
| int a        (4B) |
+-------------------+
| char symb    (1B) |
+-------------------+
| padding      (3B) |
+-------------------+

Общ размер: 8 bytes
~~~

Както виждаме, нашите данни са напълно линейно и отново срещаме подравняването добавено от компилатора за по-лесно прочитане на данни и обработка. Надявам се това е познато за вас. Нека сега разгледаме паметта на два обекта в наследяваща йерархия:

~~~.cpp
struct A
{
    int  a;      // 4 bytes
    char symb;   // 1 byte
                 // 3 bytes padding
};

struct B : A {
    float val;
    char arr[12];
};
~~~
